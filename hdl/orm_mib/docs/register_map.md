# orm_mib: Register Map

Generated by `tools/regmap.py` from `hdl/orm_mib/regs/orm_regs.yml`, do not edit.
The same description generates the VHDL package `orm_regs_pkg` and the C header `sw/orm_regs.h`.

Byte addresses of 32-bit registers on the AXI4-Lite port (10-bit address); unused addresses and bits read as zero.
The ID register reads 0x4F524D01.

| Access | Meaning |
| --- | --- |
| RO | Read only |
| RW | Read and write |
| W1 | Write one: command; reads as zero |
| W1C | Sticky flag; write one to clear |
| WO | Write only; reads as zero |
| RC | Read only; any write to the register clears it |
