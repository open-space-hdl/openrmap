# orm_pkg: Architecture and Design Description

## 1. Contents

| File | Content |
| --- | --- |
| `src/orm_pkg.vhd` | Protocol Identifier, default logical address, instruction bit positions `Instr*_c`, command kinds `CmdKind_t`, status codes `Status*_c`, decoded header `CmdHeader_t`, window configuration `WinCfg_t` and the default `WinInitOpen_c`, functions `crcUpdate`, `cmdKind`, `cmdCode`, `replyAddrBytes` |
| `src/orm_regs_pkg.vhd` | Register map (generated by `tools/regmap.py`) |

## 2. CRC

`crcUpdate(crc, data)` returns the CRC after one more byte. ECSS 5.2 forms the polynomial m(x) from the bytes in
transmission order with the least significant bit of each byte first and stores the remainder in reversed bit order
(bit 0 of the CRC byte is the coefficient of x^7). In this bit order the CRC register shifts right: the byte is
added to the register, and eight times the register shifts right by one and adds 0xE0 (the reversed polynomial
without x^8) when the bit shifted out is '1'. The register starts at zero. The RTL decoders and encoders apply the
function once per byte; it unrolls to two levels of XOR.

## 3. Command codes

| Command field (write, verify, reply, increment) | Kind |
| --- | --- |
| 0000, 0001, 0100, 0101, 0110 | Invalid |
| 0010, 0011 | Read (single address, incrementing) |
| 0111 | Read-modify-write |
| 1xxx | Write (all eight combinations of verify, reply and increment) |

## 4. Verification components (`tb/`)

| File | Content |
| --- | --- |
| `orm_tb_pkg.vhd` | `ormTestEnd`, the AXI4-Stream BFM configuration, `ormPacket` (bytes plus end of packet marker beat) |
| `orm_tb_rmap_pkg.vhd` | RMAP model: `TbCmd_t` with all command fields, `tbCommand` (command with optional CRC errors), `tbWriteReply`, `tbReadReply`, `tbReplyPath`, CRC with the table of ECSS Annex A.3, byte array helpers |
| `orm_tb_mem_pkg.vhd`, `orm_tb_memvar_pkg.vhd` | Memory of the AXI memory model as a protected type with one instance per model: backdoor access, error ranges, backpressure, statistics |
| `orm_tb_axi_ram.vhd` | AXI memory model: AXI4 slave with INCR bursts, write strobes, 16 queued commands per direction, SLVERR on the error ranges (bytes in a write error range are not written), random backpressure |
| `orm_tb_axis_master.vhd`, `orm_tb_axis_slave.vhd`, `orm_tb_axilite_master.vhd` | Wrappers of the UVVM AXI4-Stream and AXI4-Lite VVCs |
